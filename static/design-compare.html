What each brings

Linear

Ultra-premium dark mode. Inter 510 weight, indigo accent, translucent surfaces. Feels like a $1B startup's internal dashboard. Recommended if you want it to look expensive.

Supabase

Developer-tool aesthetic with emerald green identity. High-contrast borders, pill-shaped CTAs, data-dense layouts. Feels like a professional dev tool.

Raycast

macOS-native dark chrome with red accent, multi-layer shadows (inset + outer), vibrant glow effects. Feels like a premium desktop app.
